## Construindo eficiência com código

Desenvolvo **sistemas, integrações e automações** para reduzir tarefas repetitivas e conectar operações. Aplico **Python, SQL e Java** a problemas reais em diferentes áreas, incluindo dados, rotinas administrativas e operações financeiras.

Minha atuação envolve APIs REST, interfaces com React e Node.js, pipelines integrados ao Amazon S3 e indicadores em Power BI. Busco transformar processos manuais em fluxos **automatizados, confiáveis e rastreáveis**.
